GEE — Component Details

🔢 Sequencing / Prioritization

Assigns processing order to concurrent earmark requests. Implements configurable priority rules using an in-memory sorted queue (Redis-backed). Prevents race conditions via optimistic locking.

Redis QueueOptimistic LockConfigurable Priority
🔄 Excess Approval / Retry

Routes excess requests to CLUE. Implements exponential backoff retry. Dead-letter queue for unresolvable cases. Configurable retry limits per product type.

Exponential BackoffDLQCLUE Integration
🛡️ Limit Check

Per-transaction, daily aggregate, counterparty, and product-level limit validation. Integrates with Limit Management System via gRPC for real-time limit data.

gRPC LMSMulti-dimensionReal-time
🔧 Partner Specific Rules

Pluggable rule engine (Drools / custom DSL). Rules hot-reloadable from ConfigMap. Handles partner exceptions, enrichments, and field overrides without redeployment.

Hot ReloadDrools DSLConfigMap Driven

CLUE — Component Details

💰 FTS (Funding / Treasury)

Queries intraday funding availability from treasury pools. Interfaces with Treasury Management System. Returns available credit lines.

TMS IntegrationIntraday Credit
✅ Excess Approval Engine

Rule-based decision engine for approving/rejecting excess requests. Full audit trail. ML-assisted scoring planned for Phase 2.

Full AuditRule Engine
🔍 Credit Check

Validates counterparty credit exposure via AMCAR. Enforces regulatory limits (Basel III, local regulations).

Basel IIIAMCAR
📝 Credit Earmark

Creates credit-backed earmark on approval. Publishes credit events. Triggers DOL (Daylight Overdraft Limit) Block/Release via GLS.

@ApplicationScoped public class SequencingEngine { private static final Map<String, Integer> CHANNEL_PRIORITY = Map.of( "MARKETS", 1, "PAYMENT_PROCESSORS", 2, "TRADE", 3, "LOANS", 4, "CUSTODY", 5 ); @Inject RedisSequenceQueue sequenceQueue; public EarmarkRequest assignPriority(EarmarkRequest request) { int priority = CHANNEL_PRIORITY.getOrDefault( request.getChannel(), 99 ); request.setPriority(priority); // Enqueue for ordered processing per account sequenceQueue.enqueue(request.getAccountId(), request); return sequenceQueue.nextFor(request.getAccountId()); } }

Credit Engine — CLUE

Credit and Liquidity Underwriting Engine. Handles excess approval flows, credit checks, and credit-backed earmark creation.

⚡
CLUE is invoked when GEE cannot satisfy an earmark from available liquidity alone. It runs a 4-stage pipeline: Credit Check → FTS Funding Check → Excess Approval → Credit Earmark Creation.

REST Resource Implementation

JAVAapi/EarmarkRestResource.java
@Path("/api/v1/earmarks") @Produces(MediaType.APPLICATION_JSON) @Consumes(MediaType.APPLICATION_JSON) public class EarmarkRestResource { @Inject ProducerTemplate camelProducer; @Inject EarmarkRepository repository; @POST @Counted(name = "earmark.create.count") @Timed(name = "earmark.create.time") public Response createEarmark(EarmarkRequest request) { request.setEarmarkId("EMK-" + UUID.randomUUID()); camelProducer.sendBody("direct:sequencing", request); return Response.accepted() .entity(Map.of("earmarkId", request.getEarmarkId())) .build(); } @GET @Path("/{id}") public EarmarkResponse getEarmark(@PathParam("id") String id) { return repository.findById(id) .orElseThrow(() -> new NotFoundException("Earmark not found")); } @PUT @Path("/{id}/release") public Response releaseEarmark(@PathParam("id") String id) { camelProducer.sendBody("kafka:earmark.released", Map.of("earmarkId", id, "action", "RELEASE")); return Response.ok().build(); } }

Browse active partner rules, simulate rule execution against test payloads, and trigger hot-reload from ConfigMap.

SLA breach alerts, excess approval queue depth warnings, circuit breaker state, and operational runbook links.

@GrpcService public class EarmarkStreamingService extends EarmarkServiceImplBase { @Inject @Channel("earmark-created") Multi<EarmarkEvent> earmarkStream; @Override public Multi<EarmarkEvent> streamEarmarkEvents(EventStreamRequest req) { return earmarkStream .filter(e -> req.getAccountIdList().isEmpty() || req.getAccountIdList().contains(e.getAccountId())) .map(this::toProtoEvent); } }
